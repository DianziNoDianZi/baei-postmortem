# 可执行模板：把"9 条规矩"变成填空表

> 这些是 [`../BLOG.md`](../BLOG.md) 第 9 节那 9 条规矩的**可填版本**。
> 直接抄进你的实验笔记本，**在写代码之前填**。
> 它们全部来自一个被自己的对照否证的项目；每张表的"为什么"都在博客里。

---

## 表 0：前提检查（**第一张表，一天内填完；填不出来就别开工**）

| 项 | 我的答案 |
|---|---|
| 我要动手的**那一维**是什么？（一句话） | |
| 这个前提**若成立**，我应当看到什么**数字**？ | |
| 看到什么数字我就**当场杀掉它**？（可执行的阈值） | |
| 跑这一格需要的**最小装置**是什么？（目标：一小时以内跑完） | |
| 这个前提**已经被别人验过吗**？（文献/先例） | |

> 这条规矩在本项目里的价值：**15 分钟杀掉一条路**，而旧模式（先搭台子）花了**几周**。

## 表 1：预注册（跑之前写死；跑之后不许改）

```
问题 / 假设：
单变量：这个实验里我**只改**哪一样？
判据：  指标 = ______  阈值 = ______  方向 = ______（≥/≤）
下限：  效果至少要多大我才认？（写成数字，不许写"显著提升"）
null 对照：______（必须"能为 null"；做不到失败的不算对照）
打乱对照：______（探针必须带打乱标签/打乱配对的版本）
仪器检查：______（在"必然能成功"的坐标上，它必须成功）
止损线：  看到 ______ 就停，不解释、不挽救
成本预算：机时 ______ / 墙钟 ______
派生判决：结论由脚本里 if/else 从数派生（禁止硬编码结论文字）
```

## 表 2：仪器检查清单（读数出来**先过这张**，再看结果）

- [ ] **最朴素的控制**跑了吗？（"关掉它 / 静态 / 随机"——最便宜、最常被跳过的一步）
- [ ] **下游最便宜的部件**训到收敛了吗？（在我这里：读出层。否则量到的是优化预算，不是机制）
- [ ] **对手在易题上的成功率**出示了吗？（任何"对手失败"的结论，先给这个数）
- [ ] 我的对手是**真的那个**，还是**我自己手写的**？（自实现基线给出的是优势的**上界**）
- [ ] **上界（ORACLE）能到 0 吗**？（上界到不了 0 ⇒ 是任务出界或上界自身欠拟合，不是方法失败）
- [ ] **两把尺子等价吗**？（同一评测集、同一次校准、同一指标定义）
- [ ] **步数够吗**？（`n_train / batch` × epochs；不是 epoch 数）
- [ ] **结果行带提交号**吗？结论文字**由数派生**吗？
- [ ] 我看了**失败的形状**，还是只报了中心？（两个臂的失败形状不同时，中心相同的结论是假的）
- [ ] 有没有**两个数恰好相等 / 全 1.0000 / 方差为 0**？（先当 bug 查）

## 表 3：台子的"不忠实之处"（**跑之前**至少列三条）

| 项 | 我的台子 |
|---|---|
| **目标的条件熵**有多大？（确定函数 ⇒ 熵 = 0 ⇒ 谁都精确） | |
| 有没有**不可观测/没进条件**的变量？（我这里：相位） | |
| **一对多程度**如何？（同一条件对应多少种合法输出） | |
| 真值是**别人给的**，还是**我自己构造进候选里的**？ | |
| 我做的是"发现"，还是"把我放进去的答案取出来"？ | |

> 最贵的一次教训：我把目标写成一个**确定函数**，于是"精确 0.0000 bit"是在一个**不存在的任务**上的胜利。

## 表 4：公理审查（写下任何"原则"之前）

```
原则：______
它**允许**什么：______
它**禁止**什么：______          ← 这一栏是关键
我想要的那个结果，是否正落在"禁止"里？  是 / 否
如果"是"：这条原则在第一天就写好了结局 ⇒ 改原则，或者承认这个方向不可能。
```

> 我这里的实例：原则「学习必须是局部的」+ 原则「算法必须长出来」⇒ **在数学上禁止任务信息进入结构**
> ⇒ 几个月后测出的"接线跨任务 100% 相同"**是公理的推论，不是实验的发现**。

## 表 5：来源审查（从任何复杂系统借东西之前）

```
我想借的是：______（脑 / 市场 / 进化 / 物理 / …）
(a) 它能写成**一段计算**吗？            能 / 不能
(b) 我能给它挂一个"**错了会告诉我**"的指标吗？  能 / 不能
两个都不是"能" ⇒ 那就是大海捞针，不要开始。
附带一问：这一层在**源系统里承重吗**？（承重层 = 创造能力的那一层，而不是"看起来像"的那一层）
```

> 迁移成功的先例全是"能写成算法 + 能挂指标"的：卷积、TD 学习（**因果是反的**：先在 RL 里成立）、自监督目标。
> 凡是从"组织/解剖"入手的（空间嵌入、区域划分、生长规则）——**一个也没迁移**。
